# Figures and the scripts that make them

Every figure is generated by code in `scripts/`. Nothing is drawn by hand. Each PDF/PNG also carries its source
in the file metadata (PDF `Subject`, PNG `Description`): script, function, data files and framework commit.

Regenerate all figures: `.venv/bin/python scripts/make_figures.py`. One figure: `--only fig3`. Talk-sized fonts:
`--mode presentation`. The styles are `figures/styles/*.mplstyle`.
